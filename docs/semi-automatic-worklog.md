# AI Second Brain: 반자동 ChatGPT 작업 기록 v1

## 사용 가능한 기능

1. AI Second Brain 웹앱에서 **Notion 최신 데이터 조회**로 프로젝트를 불러옵니다.
2. **ChatGPT 작업 기록 · 반자동 저장**을 펼칩니다.
3. 프로젝트·날짜·제목·작업 지시·실제 완료 결과·검증 상태·다음 작업을 입력합니다.
4. **초안·ID 생성**: 동일 제목·프로젝트·날짜에 대해 안정적인 `SBG-YYYYMMDD-PROJECT-HASH-V1` ID를 생성합니다. 별도의 작업이면 제목이나 버전을 바꿉니다.
5. **ChatGPT 기록 요청 복사**: 별도 저장키 없이, ChatGPT에 붙여넣어 연결된 Notion 도구로 저장하도록 요청할 수 있습니다.
6. (선택) Vercel에 별도 `WORKLOG_WRITE_KEY`를 설정한 경우, 웹앱에서 키를 입력하여 **서버 중복 검사**를 누릅니다.
7. 검토 후 체크박스를 직접 선택하고 **승인한 작업 기록을 Notion에 저장**을 누릅니다.
8. 서버는 ID를 다시 검사하고, 새 기록 1건을 생성한 뒤 Notion 페이지 재조회로 ID와 프로젝트 관계를 확인합니다.

## 보안 경계

- `NOTION_API_KEY`: 서버 전용. 웹앱에 직접 입력하지 않습니다.
- `GRAPH_VIEW_KEY`: 조회 전용. `/api/worklog` 권한 없음.
- `WORKLOG_WRITE_KEY`: 새로운 별도 강력한 무작위 비밀키로 Vercel Production에 설정해야 합니다. 기존 조회키와 다르게 설정합니다. **채팅으로 전달하지 않습니다.**
- 비밀키가 없으면 `/api/worklog`는 503 `write_not_configured`로 쓰기를 거부합니다.
- 키 입력은 페이지 메모리에서 요청 시에만 사용하고 웹 저장소에 보관하지 않습니다.
- 공개 접근 가능한 웹앱이므로 저장키가 유출되면 제3자가 Notion에 기록할 수 있습니다. 공유 기기에서는 서버 저장 기능 사용을 피하고 주기적으로 키를 교체합니다.
- 입력 데이터는 승인 후 서버에 전송됩니다. 공개적인 원본 대화 전체를 자동으로 읽거나 전송하지 않습니다.
- `/api/worklog`는 `check`와 `save` 두 동작만 지원합니다. `save`는 사용자 승인값 필수입니다.

## 검증 및 제한

- 같은 작업 ID가 있으면 기존 페이지 URL을 반환하며 새로 생성하지 않습니다.
- 같은 ID가 여러 건이면 충돌(409)로 실패합니다.
- 조회에 실패하면 **새로 만들지 않습니다**. 쓰기 실패가 발생하면 동일 ID로 먼저 확인하고 무작정 재전송하지 않습니다.
- Notion의 작업 ID는 일반 텍스트 속성이므로 **동시에 발생한 두 요청**의 원자적 중복 방지는 보장되지 않습니다.
- 대화 종료 자동 감지, 외부 ChatGPT 대화 자동 수집 및 Claude 자동 기록은 구현되지 않았습니다.
- 서버 저장 기능은 Vercel에 별도 저장키가 설정되기 전에는 사용할 수 없습니다. 키 입력 없이 사용 가능한 복사 기능을 우선 제공합니다.
- 프로젝트별 기록을 보여 주는 그래프는 기존 읽기 전용 `/api/graph`를 유지합니다.

## 운영 절차 요약

**초안 작성 → ID 생성 → 중복 확인 → 명시적 승인 → Notion 저장 및 재조회 → 그래프 새로고침**

프로덕션 배포 성공 자체는 서버 저장 기능 실증과 다릅니다. 별도 키 설정 후 실데이터 저장·재조회와 화면 반영을 각각 검증해야 합니다.
