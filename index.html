🔗 GitHub 저장소 ↔ Notion 프로젝트 대조·등록

기존 프로젝트는 건드리지 않습니다. GitHub 저장소를 조회해 누락된 항목을 선택하고, 승인한 항목만 Notion에 새로 등록합니다.

대조 전입니다. GitHub 비공개 저장소는 서버에 별도 GitHub 연동키가 없다면 조회되지 않을 수 있습니다.

먼저 목록을 대조해 주세요. 등록 시 상태는 ‘계획’으로 설정되며 실제 구현이나 배포 완료를 의미하지 않습니다.

관계선 선택 시 관계 설명이 표시됩니다.
