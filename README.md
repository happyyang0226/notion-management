# Notion Management — AI Second Brain

Notion AI 통합 관리센터를 시각화하는 **읽기 전용** Vercel 웹앱입니다.

## 현황 (2026-11-19)
- GitHub: `happyyang0226/notion-management`, `main`
- Vercel: `notion-management` Production, 최신 코드 배포 READY 확인
- 기존 Notion 09 지식 노드 / 10 지식 관계의 실시간 조회는 사용자 화면에서 성공 확인
- 01~08의 신규 API 조회 코드는 배포되었으며, 실 데이터 조회 결과는 아직 별도 검증 필요

## 데이터 소스
- 01 프로젝트, 02 작업 지시, 03 코드·버전, 04 오류·검증
- 05 AI 작업 세션, 06 자료·산출물, 07 배포·연동, 08 결정·승인
- 09 지식 노드, 10 지식 관계

신규 01~08은 제목, 상태, Notion 페이지 URL, Notion에서 명시한 프로젝트 관계만 반환합니다.
지시 원문, 검증 메모, 환자/연구 자료 본문, 세션 지시문, 승인 근거, 오류 원인 등 상세 원문은 API 응답에 포함하지 않습니다.
접근할 수 없는 선택 데이터베이스는 경고만 표시하고 09/10 기존 그래프는 계속 조회합니다.
각 데이터베이스에 해당 내부 연결의 읽기 권한이 있어야 조회할 수 있습니다.

## 서버 비밀 설정 (Vercel Production)
- `NOTION_API_KEY`: 서버 전용 Notion 내부 연결 토큰
- `GRAPH_VIEW_KEY`: API 읽기 접근을 위한 **별도의** 강력한 키

두 값 모두 Vercel의 Secret 환경변수에만 저장합니다. GitHub·브라우저 코드·Notion 본문에는 저장하지 않습니다.
웹앱의 최신 조회는 `GRAPH_VIEW_KEY`를 사용합니다. 브라우저에 Notion API 토큰을 입력하지 마세요.

## 확인 방법
1. Vercel Production 사이트를 엽니다.
2. `Notion 최신 데이터 조회`에서 `GRAPH_VIEW_KEY`를 입력합니다.
3. 좌측 하단에 `실시간 조회 성공`이 표시되는지 확인합니다.
4. 노드 수·관계 수와 새 유형 필터를 확인합니다.
5. `일부 DB 미조회` 경고가 보이면 연결의 페이지 사용 권한에서 해당 데이터베이스를 허용했는지 확인합니다.
